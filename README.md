# Customer Churn Prediction Platform

## Overview

This project focuses on predicting customer churn using machine learning and data analytics techniques. The goal is to identify high-risk customers, analyze churn drivers, and provide actionable business insights that support customer retention strategies.

---

## Tools & Technologies

- Python
- SQL
- PostgreSQL
- pandas
- scikit-learn
- Power BI
- Jupyter Notebook

---

## Project Objectives

- Analyze customer behavior and churn patterns
- Perform exploratory data analysis (EDA)
- Build predictive machine learning models
- Identify key churn indicators
- Visualize business insights using dashboards

---

## Machine Learning Models

Planned models include:
- Logistic Regression
- Random Forest
- XGBoost
